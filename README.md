# CustWebHtml - Customers Web Html Website

IndiFly365 - Customers Web Html Website for Flight(s) Booking(s)

## Getting started

Clone an existing Git repository with the following command:

1. cd ../workspace/IndiFly/Prod/Flight-Web/
2. Clone the repo using following git command: `git clone https://github.com/MetrixIT-IndiFly365/IndiFly365.Html.git`
3. Go to the appropriate directory to start the App: `cd IndiFly365.Html`

Push an existing Git repository with the following command:

```
cd existing_repo
git remote add origin https://github.com/MetrixIT-IndiFly365/IndiFly365.Html.git
git branch -M main
git push -uf origin main
```
